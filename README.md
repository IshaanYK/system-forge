# system-forge

Systems programming toolkit, memory profiling utilities, process monitors, and async task orchestrators.

## Overview
A production-grade, well-tested repository engineered with high performance, modular design, and robust test coverage.

## Features
- **Zero External Dependencies**: Clean, pure implementations.
- **Strict Typing**: Fully typed with Python type hints (`typing`).
- **Comprehensive Test Suite**: Automated unit tests and regression assertions.
- **Benchmark Driven**: Micro-benchmarked for sub-millisecond execution times.

## Installation

```bash
git clone https://github.com/IshaanYK/system-forge.git
cd system-forge
pip install -r requirements.txt
```

## Running Tests

```bash
python -m unittest discover tests
```
